# Sign-Up Form

Responsive sign-up form built with semantic HTML and CSS as part of The Odin Project curriculum.

## Features
- Responsive split-screen layout
- Accessible form structure
- Custom focus and validation styles
- Semantic HTML5 markup
- CSS Flexbox layout

## Technologies Used
- HTML5
- CSS3
- Javascript

## What I Learned
- Form accessibility
- Input styling and validation states
- Layout structuring with Flexbox
- Visual hierarchy in UI design
